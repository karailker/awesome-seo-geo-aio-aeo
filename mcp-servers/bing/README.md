# @karailker/awesome-seo-mcp-bing

MCP server for Bing Webmaster (search stats, page stats, URL info; URL submit behind the approval gate). Part of the awesome-seo Claude Code plugin.

Run it with npx (credentials come from environment variables, never from this package):

```bash
npx -y @karailker/awesome-seo-mcp-bing
```

See the repository for setup and credentials: https://github.com/karailker/awesome-seo-geo-aio-aeo
