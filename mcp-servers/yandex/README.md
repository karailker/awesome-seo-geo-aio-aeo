# @karailker/awesome-seo-mcp-yandex

MCP server for Yandex Metrica and Yandex Webmaster (read tools; sitemap add behind the approval gate). Part of the awesome-seo Claude Code plugin.

Run it with npx (credentials come from environment variables, never from this package):

```bash
npx -y @karailker/awesome-seo-mcp-yandex
```

See the repository for setup and credentials: https://github.com/karailker/awesome-seo-geo-aio-aeo
