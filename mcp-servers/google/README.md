# @karailker/awesome-seo-mcp-google

MCP server for Google Search Console, GA4, and Merchant Center (read tools; sitemap submit behind the approval gate). Part of the awesome-seo Claude Code plugin.

Run it with npx (credentials come from environment variables, never from this package):

```bash
npx -y @karailker/awesome-seo-mcp-google
```

See the repository for setup and credentials: https://github.com/karailker/awesome-seo-geo-aio-aeo
