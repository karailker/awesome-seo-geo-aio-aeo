# @karailker/awesome-seo-mcp-performance

MCP server for PageSpeed Insights, CrUX, and local Lighthouse (lab and field kept separate). Part of the awesome-seo Claude Code plugin.

Run it with npx (credentials come from environment variables, never from this package):

```bash
npx -y @karailker/awesome-seo-mcp-performance
```

See the repository for setup and credentials: https://github.com/karailker/awesome-seo-geo-aio-aeo
