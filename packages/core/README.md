# @karailker/awesome-seo-core

Shared core for the awesome-seo Claude Code plugin (version 0.1.0, MIT): SQLite store (WAL, foreign keys), Drizzle schema and versioned migrations, ingest for sitemap, crawl, Search Console, GA4, Bing, Yandex Metrica and Webmaster snapshots, evidence-gated reports, and the write-approval engine.

Used by the MCP servers (`@karailker/awesome-seo-mcp-*`). Repository: https://github.com/karailker/awesome-seo-geo-aio-aeo
